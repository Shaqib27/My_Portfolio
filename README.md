# Md Shaqib Hussain — Portfolio

A responsive Next.js portfolio showcasing selected projects, professional experience, skills, a personal introduction, education, and contact links.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Before deploying, run `npm run lint`, `npm run typecheck`, and `npm run build`.

## Update your content

- Edit project descriptions, skills, and navigation in `src/data/portfolio.ts`.
- Update résumé details and contact or social links in `src/components/portfolio-page.tsx`.
- Replace `public/files/Md_Shaqib_Hussain_Resume.pdf` when you update your résumé.

The résumé file in `public/files/` is publicly downloadable when the site is deployed. The interface uses locally rendered CSS illustrations rather than relying on external image assets or font requests.
